# هديتنا — بوكس رمضان

صفحة هبوط عربية RTL لبوكس هدايا رمضان، مبنية بـ Next.js App Router وTypeScript وTailwind CSS.

## التشغيل المحلي

1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. (اختياري) انسخ `.env.example` إلى `.env.local` إذا أردت تفعيل Meta Pixel.
4. شغّل `npm run dev` وافتح `http://localhost:3000`.

## تغيير الاسم والأسعار والصور

- عدّل `lib/site-config.ts` لتغيير اسم هديتنا والسعر الأصلي وسعر العرض ورسوم التوصيل ومناطق التوصيل والعدّ التنازلي والصور.
- استبدل `public/logo.svg` بالشعار الجديد، مع الحفاظ على الاسم `logo.svg` أو غيّر مسار `logoPath` في الإعدادات.
- الصور الحالية موجودة في `public/images/`. استبدل الصور مع الحفاظ على الأسماء أو حدّث `galleryImages`.
- ألوان الموقع معرفة كمتغيرات CSS في بداية `app/globals.css`، وكذلك كـ Tailwind theme tokens في `tailwind.config.ts`.

## العدّ التنازلي

في `lib/site-config.ts`:

- `mode: "per-visitor"` يبدأ عند أول زيارة ويحفظ وقت البداية في `localStorage`، ثم يكمل العدّ في الزيارات التالية.
- `mode: "fixed"` يستخدم `fixedEndDate` بتوقيت ISO.
- `onExpire: "restore-original-price"` يعرض السعر الأصلي بعد انتهاء المهلة. `onExpire: "keep"` يبقي السعر المخفّض.
- لو منع المتصفح التخزين المحلي، يعمل المؤقت للجلسة الحالية.

## استلام الطلبات على WhatsApp

النموذج يجهّز رسالة فيها الاسم والعنوان ورقمي الهاتف والسعر والتوصيل، ثم يفتح محادثة WhatsApp مع `01148948425` بصيغة دولية. العميل يحتاج الضغط على **إرسال** داخل WhatsApp حتى تصلك الرسالة.

هذا المسار لا يحتاج Google Sheets أو WhatsApp Business API أو توكن، ولا يحفظ بيانات النموذج على الموقع. لذلك لا يظهر الطلب عندك إلا إذا أكمل العميل الإرسال في WhatsApp؛ ولا يستطيع الموقع معرفة إن كان ضغط إرسال بالفعل.

## إعداد Meta Pixel

ضع `NEXT_PUBLIC_META_PIXEL_ID` إذا أردت تفعيله. عند تركه فارغًا لا يُحمّل Pixel. يُسجل التطبيق PageView وInitiateCheckout عند أول تركيز على حقل وLead بعد نجاح الطلب.

## ملاحظات تشغيلية

- صور المنتج المرسومة في `public/images/` هي رسومات SVG محلية قابلة للاستبدال.
- عند استخدام رابط WhatsApp، قد يفتح التطبيق أو WhatsApp Web حسب الجهاز والمتصفح.

## النشر على Vercel

ارفع المشروع إلى Git، ثم استورده في Vercel. أضف متغير `NEXT_PUBLIC_META_PIXEL_ID` فقط إذا رغبت في تفعيل Meta Pixel، ثم انشر.
